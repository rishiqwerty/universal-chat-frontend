# 🧠 Neural Architect: Universal Chat Frontend

A high-performance, premium AI chat interface built with React, Vite, and Framer Motion. This frontend provides a unified experience for interacting with multiple AI providers (OpenAI, Anthropic, Gemini) with real-time streaming and multi-modal support.

---

## 🗺️ Documentation & Architecture

👉 **[Frontend Engineering Guide](./docs/FRONTEND_GUIDE.md)**

---

## 🚀 Features

- **Multi-Provider Support**: Seamlessly switch between OpenAI, Anthropic, and Gemini.
- **Real-Time Streaming**: Instant token-by-token responses using Server-Sent Events (SSE).
- **Multi-Modal Synthesis**: Direct support for image generation and display within the chat.
- **Premium UI**: Ultra-dark mode, glassmorphism, and smooth layout transitions using Framer Motion.
- **Secure Persistence**: Local management of model preferences and conversation history.

---

## 🛠️ Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

The app will be available at `http://localhost:5173`.
